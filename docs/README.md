# About solution
this solution implements additional math formulas such as <ins>area</ins> and <ins>perimeter</ins> for squares, circles and rectangles

# Math formulas
## Area
- Circle: ***S = πR²***  
    ```
    r = 10
    print(area(r)) # 314.1592653589793
    ```

- Square: ***S = a²***  
    ```
    a = 10
    print(area(r)) # 100
    ```

- Rectangle: ***S = ab***  
    ```
    a = 5
    b = 10
    print(area(a, b)) # 50
    ```
## Perimeter
- Circle: ***P = 2πR***  
    ```
    r = 10
    print(area(r)) # 62.83185307179586
    ```

- Square: ***P = 4a***  
    ```
    a = 10
    print(area(r)) # 40
    ```

- Rectangle: ***P = 2ab***
    ```
    a = 5
    b = 10
    print(area(a, b)) # 30
    ```
